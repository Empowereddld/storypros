# Story illustrations

Drop each story's art here in a folder named after the story's `id`
(from its JSON), e.g.:

  src/assets/stories/dan-and-the-paper-cut/slide-01.png ... slide-06.png
  src/assets/stories/dan-and-the-paper-cut/vocab-bandage.png
  src/assets/stories/dan-and-the-paper-cut/joke-stick-1.png

The resolver (src/services/storyImages.ts) picks them up automatically.
